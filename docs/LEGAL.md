# Правовая позиция Hanten

Коротко: приложение не хранит и не распространяет чужой контент.

## Что делает приложение

- Hanten — клиент для чтения. Он открывает страницы, которые уже опубликованы
  на сторонних сайтах, и показывает их в удобном виде.
- Источники — это описания сайтов, а не копии их контента. Приложение не
  поставляет главы, книги, изображения или обложки вместе с APK.
- Приложение не обходит платный доступ, авторизацию, DRM и не выдаёт платный
  контент за бесплатный.

## Ответственность

- Права на контент принадлежат авторам, переводчикам и правообладателям.
- Претензии об удалении контента (DMCA и аналогичные) направляются владельцам
  сайтов, где этот контент размещён. Разработчики Hanten не связаны с такими
  сайтами.
- Пользователь сам выбирает источники и отвечает за соблюдение местных законов
  и правил выбранных сайтов. Приложение не поощряет нарушение авторских прав.

## Что можно удалить из проекта

- Код, иконки, шрифты и другие собственные материалы Hanten — по обоснованному
  запросу через issue в репозитории.
- Ссылки на источники удаляются из каталога, если сайт прекратил работу,
  распространяет вредоносный контент или нарушает закон.

## Релизный чеклист

- В APK нет скачанных глав, книг, обложек и баз источников с контентом.
- В приложении нет встроенных «обходных» источников с платным контентом.
- README и экран «О приложении» содержат отказ от ответственности.
- При добавлении источника проверяется, что парсер не ломает авторизацию,
  платный доступ и DRM сайта.
