# TODO 2.8.0 — один релиз

Цель: один релиз вместо серии мелких обновлений. Ручные связи убираем,
автоматические подсказки показываем текстом на странице произведения.
Промежуточных тегов нет: `2.8.0` ставится только после полной проверки.

## B. Sprint 0 — стабильность

- [x] ReadManga auth: проверка `window.current_user_id`, вход через
      `/internal/auth`, распознавание страницы логина. Код в
      `hanten-parsers` закоммичен и помечен `v2026.11.14`; JitPack
      ещё не собрал артефакт. После сборки поднять `parsers` в
      `libs.versions.toml` и проверить вход с аккаунтом.
- [x] Импорт EPUB/PDF из `content://` (не только tree URI); файл
      копируется в управляемую папку.
- [x] Скачивание/удаление глав новелл из деталей идёт через
      `NovelDownloadScheduler`/`NovelOfflineRepository`.
- [x] Ярлыки и виджеты: `ReaderActivity` перенаправляет новеллу/PDF
      в нужную читалку по `mangaId`.
- [x] Троттлинг прогресса: `HistoryRepository` больше не переписывает
      главы; новеллы сохраняют прогресс не чаще раза в 5 секунд и в
      `onPause`.
- [x] Сохранение позиции в `onPause`.
- [x] Очередь загрузок новелл: строка удаляется после успешного
      завершения воркера, а не сразу после enqueue; пауза обновляет
      существующую строку.
- [x] Pause/resume/cancel новелл в общем экране загрузок (кнопки и
      «пауза всех»); строки очереди обновляются, а не дублируются.
