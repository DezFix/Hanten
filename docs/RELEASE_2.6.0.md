# Hanten 2.6.0

## Что нового

- **Ranobe.me** — новый русскоязычный источник новелл: каталог, поиск, жанры,
  обложки, список глав и чтение.
- **Правовой раздел** в «О приложении» и `docs/LEGAL.md`: приложение не хранит
  и не распространяет контент, а претензии по DMCA направляются владельцам
  сайтов-источников.
- **Читалка новелл** учитывает системные отступы и высоту шапки/нижней панели,
  поэтому текст больше не уходит под строку состояния.
- **Закладки в новеллах** — глава + процент; закладка видна в общем списке и
  открывает книгу на сохранённом месте.
- **Общие настройки чтения** — «не гасить экран», ориентация, кнопки громкости
  и инкогнито теперь работают и для новелл.

## Исправления

- Экран первого запуска теперь учитывает новеллы: источники выбираются по языку
  и типу контента, а не включаются скрытно.
- Включённый источник новелл исчезает из каталога после добавления — как манга.
- Новеллы можно отключать и включать в общем списке источников.
- Счётчики доступных источников и эксклюзивное включение учитывают новеллы.
- RanobeLib больше не показывает сырой JSON: текст конвертируется в HTML
  (абзацы, цитаты, списки, заголовки, разделители, форматирование, картинки).
- Поля читалки пересчитываются из dp в px.
- Картинки в главах разрешаются относительно домена источника, а не
  `futon.reader`.
