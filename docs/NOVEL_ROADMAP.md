# План развития режима новелл

Цель: новеллы должны уметь всё то же, что манга, но с учётом текста.
Режим — глобальный: кнопка в шапке переключает весь интерфейс (источники,
поиск, историю, избранное, загрузки, статистику, «Продолжить»).

## Что уже есть

- Два режима и фильтрация по ним в Explore, поиске, подсказках, избранном,
  истории, «Похожих» и каталоге источников.
- Источники: Ranobes, RanobeLib, Ranobe.me (RU), Baka.in.ua (UK); обложки,
  карточка, список глав, чтение.
- Читалка: прокрутка и постраничный режим, размер шрифта, 3 семейства,
  межстрочный интервал, абзацный отступ, поля, выравнивание, темы
  (dark/light/OLED/sepia/custom), бесконечная подгрузка следующей главы.
- Локальные новеллы: EPUB, PDF, папки.
- Smart Resume и prefetch — только для манги.

## Чего не хватает (паритет с мангой)

| Возможность | Манга | Новеллы | Приоритет |
|---|---|---|---|
| Общий каталог парсеров, настройки источника (домен/зеркало, UA), закрепление, «открыть источник» | есть | нет: свои `NovelParserSource` и репозитории | P0 |
| Фильтры источника: жанры, теги, статус, год | есть | нет: `getFilterOptions()` пустой | P0 |
| «Продолжить» с учётом режима | — | нет: берёт последнюю запись из общей истории | P0 (баг) |
| Оглавление (TOC) в читалке | есть (главы) | нет | P0 |
| Восстановление позиции прокрутки при открытии/повороте | есть (страница) | нет: всегда открывается с начала главы | P0 |
| «Глава прочитана», Smart Resume для новелл | есть | нет | P1 |
| Закладки в тексте, заметки | есть (страница) | нет | P1 |
| Поиск по главе и по книге | нет | нет | P1 |
| Скачивание глав и офлайн-чтение | есть | нет: download-контур не знает про текст | P1 |
| Статистика чтения | есть | нет | P2 |
| Озвучка (TTS) | нет | нет | P2 |
| Случайная новелла из источника | есть | проверить, скорее работает | P2 |

| PDF: зум, обрезка полей, ночной режим | — | нет | P2 |

## Читалка: что улучшить в первую очередь

### P0 — баги и заметные неудобства

1. **Referer для картинок внутри глав.** В `NovelReaderActivity` жёстко
   зашит `Referer: https://lnori.com/`. Для RanobeLib/Baka картинки в тексте
   будут отдавать 403. Нужен referer текущего источника (как в
   `CommonHeadersInterceptor`).
2. **Сохранение и восстановление позиции.** Сейчас при открытии глава
   начинается с нуля, `scrollProgress` живёт только в сессии. Нужно:
   сохранять `scroll`/страницу в историю и восстанавливать после загрузки
   (и после поворота экрана).
3. **Смена настроек не должна терять позицию.** Сейчас
   `onNovelSettingsChanged` заново рендерит документ. Правильно — менять CSS
   через JS и сохранять `scrollTop`/номер страницы.
4. **Оглавление.** Шит со списком глав, отметкой текущей, прочитанных и
   переходом по тапу. Сейчас есть только «предыдущая/следующая».
5. **«Продолжить» игнорирует режим.** `MainViewModel.openLastReader()` берёт
   последнюю запись общей истории; в режиме новелл может открыть мангу.

### P1 — то, что делает чтение комфортным

6. **Тап-зоны**: левая/правая треть — листать страницу (в paged) или главу,
   центр — показать/скрыть интерфейс (центр уже есть).
7. **Слайдер прогресса**: переключатель «глава / книга»; сейчас показывает
   только главу, а «4 / 153» — номер главы.
8. **Префетч следующей главы**: подгружать текст заранее, как страницы манги,
   чтобы бесконечная прокрутка не упиралась в паузу.
9. **«Глава прочитана» и Smart Resume.** Тем же правилом, что для манги:
   дочитал главу N−1 → при открытии продолжить с N, если появились новые.
10. **Закладки и заметки.** Якорь — глава + абзац (id абзаца в HTML), список
    закладок из читалки и из карточки.
11. **Поиск по главе/книге** с подсветкой и переходом.
12. **Полноэкранный режим, яркость, «не гасить экран», блокировка ориентации**
    — как в настройках ридера манги.
13. **Paged-режим**: корректный номер страницы и прогресс, анимация
    перелистывания, сохранение страницы при смене шрифта/размера.

### P2 — развитие

14. **TTS**: озвучка главы, управление из уведомления, автопереход.
15. **Выделение текста**: копировать, поделиться, перевести, искать в
    интернете.
16. **Шрифты**: импорт своих TTF/OTF, вес, курсив, буквица; проверка
    кириллицы.
17. **Темы**: больше готовых пресетов, отдельные цвета ссылок/выделения.
18. **Автоскролл** для длинных глав (по аналогии с FAB в манге).
19. **Кэш глав на диск** + офлайн-чтение (см. этап 3).
20. **EPUB/PDF**: картинки и сноски в EPUB, TOC из файла; зум и поля в PDF.

## Этапы

### 2.6 — источники и навигация

1. Перевести новеллы на общий `MangaParserSource` (парсеры уже в
   `hanten-parsers`, группа `site/novel`): удалить `NovelParserSource` и
   `novel/data/source/*`, проверки — по `contentType == NOVEL`.
   Это автоматически даёт настройки источника, зеркала, закрепление,
   «открыть источник», единый каталог и фильтры.
2. Жанры/теги/статус в парсерах: RanobeLib (жанры из API), Ranobes
   (`/cloud/genre/`), Baka (жанры каталога).
3. «Продолжить» и «Случайная» с учётом режима.
4. Оглавление в читалке, восстановление позиции, referer картинок.
5. Отметка прочитанных глав в списке.

### 2.7 — читалка

6. Тап-зоны, слайдер «глава/книга», префетч, Smart Resume для новелл.
7. Закладки/заметки, поиск, выделение текста.
8. Полноэкранный режим, яркость, keep screen on, ориентация.
9. Paged-режим до конца: страницы, анимация, сохранение позиции.
10. TTS.

### 2.8 — офлайн и данные

11. Скачивание глав (текст + картинки) и офлайн-читалка; отдельный экран
    загрузок для новелл.
12. Кэш глав в Room/файлах, очистка, лимиты.
13. Статистика чтения новелл.
14. EPUB/PDF-доработки.

## Форматы скачивания

- **Сейчас:** онлайн-главы читаются только с источником; локально поддерживаются
  импортированные EPUB и PDF. Скачивание глав новелл не реализовано, кнопка
  скачивания скрыта.
- **Этап 1 (2.7):** кэш глав в файлах (HTML/текст + картинки) и офлайн-чтение
  из того же читателя. Это закрывает основной сценарий «читать в метро» без
  новых форматов и без экспорта.
- **Этап 2:** экспорт книги в EPUB. EPUB — открытый формат, уже есть парсер,
  а HTML глав переиспользуется почти без изменений. PDF для художественного
  текста не подходит: нет переформатирования под экран.
- **Не делаем:** MOBI/AZW3 (проприетарные, привязка к Kindle) и FB2-экспорт
  в ближайших версиях. FB2 можно добавить позже как импорт, если будет спрос.

## Технические предпосылки

- **Модель данных.** Новелла сейчас — `Manga` с текстовой страницей
  (`MangaPage.url` = HTML). Для закладок/загрузок/кэша нужен слой
  «глава → текст» (Room: `novel_chapters`, `novel_progress`), иначе
  bookmarks/downloads продолжают думать картинками.
- **Единый источник правды по источникам.** После переезда на
  `MangaParserSource` исчезнут ветвления `isNovelSource` в
  `MangaRepository.Factory`, `FaviconFetcher`, `MangaSourcesRepository`.
- **Режим.** Все входы в контент (`openLastReader`, уведомления, ярлыки,
  «Продолжить», downloads) должны фильтровать по текущему `AppMode`.

## Риски

- Переезд на общий парсер-каталог — самый крупный шаг: нужен новый релиз
  `hanten-parsers` и проверка JitPack; без миграции приложения поднимать
  версию парсеров нельзя (дубли имён источников).
- Кэш текста и загрузки потребуют миграции БД.
- TTS и выделение текста зависят от WebView и по-разному ведут себя на
  Android 6–15.
