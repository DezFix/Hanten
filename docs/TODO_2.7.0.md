# План 2.7.0: одно пространство + связанные произведения

Цель: манга, манхва и ранобэ живут в одном списке, с метками типа и общим меню
скачивания. Глобальный режим `AppMode` удалён.

## 1. Одно пространство

- [x] Удалён `AppMode`, переключатель в меню, ключ настроек.
- [x] Убраны фильтры `isNovel` из истории, избранного, поиска, подсказок,
  источников, «Продолжить», случайной.
- [x] Локальная библиотека — один экран.
- [x] Поиск ищет и локальные мангу, и локальные новеллы.
- [x] Источники одного сайта (манга + ранобэ) больше не скрываются режимом.

## 2. Метки типа

- [x] `MangaSource.contentType` / `Manga.contentType`.
- [x] Метка в карточке сетки, в списке, в подробном списке, в шапке деталей.
- [x] Метка в едином экране загрузок.

## 3. Единые загрузки

- [x] Один экран `DownloadsActivity`: манга (WorkManager) + новеллы
  (активные работы + скачанные книги).
- [x] Удалён `NovelDownloadsActivity` и его пункт меню.
- [x] Snackbar после постановки ведёт в общий экран.

## 4. Связанные произведения

- [x] Таблица `manga_relations` (миграция 32→33), типы связей, репозиторий.
- [x] Блок «Связанные произведения» в деталях (ручные + от источника).
- [x] Добавление/удаление связи через меню деталей.
- [x] Секция в бэкапе.
- [x] Связи от novel-парсеров (отдельный релиз `hanten-parsers`).

## 5. Релиз

- [x] Версия 2.7.0 / 20700.
- [x] `:app:testDebugUnitTest`, `:app:lintDebug`.
- [x] Коммит, пуш, тег `v2.7.0`.
