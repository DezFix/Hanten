# Паритет манги и новелл

Матрица того, что уже одинаково, что отличается и что делать дальше.
Обновлено для 2.6.0.

## Уже одинаково

- Два глобальных режима: обзор, поиск, избранное, история, «Продолжить»,
  локальные файлы, «Похожие», случайная книга.
- Каталог источников, включение/отключение, сортировка, закрепление,
  фильтр по языку и типу контента, первый запуск.
- Карточка произведения: обложка, описание, жанры, автор, главы, статус,
  избранное, «Похожие», «Поделиться», открытие в браузере.
- Читалка: прогресс, восстановление позиции, оглавление, следующая/предыдущая
  глава, подгрузка следующей главы, тап-зоны, темы, шрифт, интервалы,
  выравнивание, поля.
- Общие настройки чтения: «не гасить экран», ориентация экрана, кнопки
  громкости, инкогнито.
- Системные отступы: текст не уходит под статус-бар, шапку и нижнюю панель.

## Приоритеты

### P0

1. **Офлайн-чтение.** Кэш главы (HTML + картинки) в файлах, экран загрузок,
   удаление, лимит кэша. Формат — внутренний кэш, не книга.
2. **Закладки в тексте.** Сейчас закладка ставится на главу и процент.
   Следующий шаг — якорь на абзац (`id` у `<p>`), чтобы открывать точное место.

### P1

3. **Smart Resume для новелл.** Если глава дочитана до порога, открывать
   следующую; ждать обновлений, как в манге.
4. **Автопрокрутка.** Скорость в настройках, пауза по тапу, остановка в конце
   главы.
5. **Настраиваемые тап-зоны.** Переиспользовать `TapGridSettings`: левая/правая
   зона — страница или глава, центр — интерфейс, долгий тап — меню.
6. **Полноэкранный режим.** Скрывать статус-бар и панель навигации по настройке,
   с восстановлением по тапу.
7. **Экран загрузок для новелл.** Отдельный список книг/глав, прогресс, отмена.

### P2

8. Настройки источника для новелл: домен/зеркало, User-Agent, cookies.
9. Статистика чтения новелл.
10. Экспорт в EPUB.
11. TTS, поиск по книге, выделение текста, заметки.
12. Свои шрифты (TTF/OTF) с проверкой кириллицы.

## Что не нужно переносить

- Двойные страницы, зум, кроп, цветовые фильтры, сохранение страницы — это
  свойства изображений, а не текста.
- Трекеры MAL/Shikimori не поддерживают веб-новеллы; включать их для новелл
  не нужно.
