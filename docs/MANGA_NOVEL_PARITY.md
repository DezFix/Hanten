# Паритет манги и новелл

Матрица того, что уже одинаково, что отличается и что делать дальше.
Обновлено для 2.6.0.

## Уже одинаково

- Два глобальных режима: обзор, поиск, избранное, история, «Продолжить»,
  локальные файлы, «Похожие», случайная книга.
- Каталог источников, включение/отключение, сортировка, закрепление,
  фильтр по языку и типу контента, первый запуск.
- Карточка произведения: обложка, описание, жанры, автор, главы, статус,
  избранное, «Похожие», «Поделиться», открытие в браузере.
- Читалка: прогресс, восстановление позиции, оглавление, следующая/предыдущая
  глава, подгрузка следующей главы, тап-зоны, темы, шрифт, интервалы,
  выравнивание, поля.
- Общие настройки чтения: «не гасить экран», ориентация экрана, кнопки
  громкости, инкогнито, полноэкранный режим.
- Закладки, Smart Resume, автопрокрутка, офлайн-кэш и экран загрузок.
- Системные отступы: текст не уходит под статус-бар, шапку и нижнюю панель.

## Приоритеты

### P0 — закрыто в 2.6.0

1. **Офлайн-чтение.** Файловый кэш главы (HTML + картинки), ручное скачивание
   книги, экран загрузок и удаление. Осталось: очередь/отмена, лимит кэша.
2. **Закладки в тексте.** Глава + процент + индекс абзаца; открытие из общего
   списка возвращает к абзацу.

### P1 — закрыто в 2.6.0

3. **Smart Resume для новелл.** Порог по проценту, переход к следующей главе.
4. **Автопрокрутка.** Скорость, пауза по тапу, остановка в конце документа.
5. **Настраиваемые тап-зоны.** Левая/правая треть: страница или глава.
6. **Полноэкранный режим.** Скрытие системных баров по настройке.

### Следующие шаги

7. Очередь загрузок, отмена, лимит кэша и автоочистка.
8. Полный 3×3 редактор тап-зон и настройка набора кнопок.
9. Настройки источника для новелл: домен/зеркало, User-Agent, cookies.
10. Статистика чтения новелл.
11. Экспорт в EPUB.
12. TTS, поиск по книге, выделение текста, заметки.
13. Свои шрифты (TTF/OTF) с проверкой кириллицы.

## Что не нужно переносить

- Двойные страницы, зум, кроп, цветовые фильтры, сохранение страницы — это
  свойства изображений, а не текста.
- Трекеры MAL/Shikimori не поддерживают веб-новеллы; включать их для новелл
  не нужно.
